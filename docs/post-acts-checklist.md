# Post-Acts Checklist — Standard

> Checklist items are intended for both Project Head and DocuLogi review.


## Proof of Financial Submission

- [ ] ask your fin-in-charge if the submission of your activity's financial documents have been reflected in the FRS. If not, submit a proof of financial submission
  - proof of financial submission contains a screenshot of the email submission to the EVC-F; get this from your fin-in-charge

## Pre-Activity Requirements

- [ ] include pre-activity requirements

## Activity Report (All Parts)

- [ ] make sure to follow ALL text format and alignment indicated in the template (bold, aligned middle/left/center, justified)

## Activity Report Part I

- [ ] make sure all Activity Details are EXACTLY the same with A-Form/SAS
- [ ] tie-ups must be consistent with attached MoAs
- [ ] Table 2:
  - If activity is Termlong/Yearlong w/o synch activity:
  - indicate the Date and Venue above Table 2
  - do NOT remove the table
  - put N/A for all
- [ ] If activity is synchronous/with participants:
  - make sure that the numbers you put are correct (ENP/ENMP from A-Form, ANP/ANMP must be correct)
- [ ] If activity is synchronous with multiple dates:
  - create a table for EACH synch activity date
- [ ] If activity is asynchronous/online posting:
  - indicate Date, Venue above Table 2
  - put N/A for all

## Activity Report Part II

- [ ] objectives must be EXACTLY the same with the attached PPR
- [ ] answers on the third column must be related to the corresponding objective

## Activity Report Part III

- [ ] numbers 1-3 are required for both tables (strictly answer the guide indicated in the template)
  - limit answers to 1-2 sentences ONLY
  - remove rows 4 and 5 if you are not going to add other factors
- [ ] what went well and what went wrong must be WITHIN the activity
  - see the guidelines to know which are valid answers
- [ ] Recommendation(s) must be related to the What Went Wrong column

## Activity Report Part IV

- [ ] answers must be 1-2 sentences ONLY
- [ ] remove guide questions after answering
- [ ] answers must be in sentence form (subject-predicate)

## List of Pictures (for synchronous activities only, delete if not applicable

- [ ] make sure all Activity Details are EXACTLY the same with A-Form/SAS
- [ ] at least 3 pictures; can be 2 pics of the participants and 1 pic of the event proper or 1 pic of the participants and 2 pics of the event proper (at least 1 pic of participants is required)
  - for the pic of participants, please make the caption about the participants (e.g. The participants were asked to turn on their cameras for a group picture after the event.)
- [ ] if venue is Discord, picture of the participants must be in grid format, similar to Zoom (see picture for reference)
  - if event is live streamed, picture of participants is not required
- [ ] captions must be in sentence form (subject-predicate)

## General Attendance Log Sheet (GALS) (for synchronous activities only, delete if not applicable)

- [ ] make sure that all Activity Details are EXACTLY the same with A-Form/SAS
- [ ] if one-day activity, remove the "for multiple-day activities" template
  - if multiple-day activity, remove the "for one-day activities" template
- [ ] make sure to input the correct ANP and ANMP (counted from GALS responses)
  - ANMP should be all responses that answer "Member"
  - ANP should be ALL responses ("Member" + "Non-Member")
- [ ] make sure that the link for GALS responses is VIEWABLE
- [ ] remove duplicate entries in the sheets, if there is any
- [ ] For multiple date activities, ensure that the entries for each day are separated into different sheets/tabs.
- [ ] link must be directed to the Google Sheet responses NOT the actual google form

## Approved Flyer/Poster (delete if not applicable)

- [ ] make sure that all Activity Details are EXACTLY the same with A-Form/SAS
- [ ] include at least one approved pub material
- [ ] captions per pub are NOT required
- [ ] include screenshots / email verification of at least 1 PNP approval for the pubs
- [ ] if pub is a video, submit a screenshot

## Evaluation Results (for Academic - Seminar/Workshop and OrgDev - General Assembly only, delete if not applicable)

- [ ] acquire evaluation results from ORGRES and include it in the post-acts; evaluation results can be found in the project head's email 1-2 days after the synch activity date
- [ ] project head must sign the evaluation result; there is a space for signatures on the lower right of the evaluation results document

## Podcast Post-Acts Requirements (for Podcast only, delete if not applicable)

- [ ] for Podcast Links, please make sure that all links are correct and working
  - for Discussion Points Report, please make sure that all Activity Details are EXACTLY the same with A-Form/SAS

## Signed Broadcast Consent Forms (delete if not applicable)

- [ ] have broadcast consent forms signed and include it in the post-acts

## Fund Raising Activity (FRA) Report (for FRAs only, delete if not applicable)

- [ ] no need to include in the post-acts

## List of Sponsors (for Solicitations/Sponsorships only, delete if not applicable)

- [ ] please include list of sponsors

## Memorandum of Agreement (for Tie-Up Activities and activities with partners only, delete if not applicable)

- [ ] for Internal and External MoA:
  - include approved and signed MOA in the post-acts
- [ ] include Email Verification for all signatories (except project heads)

## List of Participants and Winners (for Contest/Competition only, delete if not applicable)

- [ ] make sure that all Activity Details are EXACTLY the same with A-Form/SAS
- [ ] include list of ALL participants with ID number
- [ ] include list of ALL winners with ID number

## List of Accepted Applicants (for Recruitment/Applications only, delete if not applicable)

- [ ] make sure that all Activity Details are EXACTLY the same with A-Form/SAS
- [ ] include list of ALL accepted applicants with ID number

## List of Donations (delete if not applicable)

- [ ] make sure that all Activity Details are EXACTLY the same with A-Form/SAS
- [ ] list down all donors and the amount donated

## List of Prizes (for Team Building Activity only, delete if not applicable)

- [ ] include list of prizes

## Members Feedback Responses (for Academic Assistance and synchronous Contest/Competition only, delete if not applicable)

- [ ] make sure that all Activity Details are EXACTLY the same with A-Form/SAS
- [ ] make sure that the link for members feedback responses is VIEWABLE
- [ ] link must be directed to the Google Sheet responses NOT the actual google form
