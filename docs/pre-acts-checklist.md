## A-Form

- [ ] Requesting Organization: Should always be "La Salle Computer Society", not LSCS
- [ ] Activity Title: Check if it is exactly the same as stated in the GOSM/Notion Page
  - Make sure the title of the activity is at least similar. If the title is completely different from the blanket, FA signature must be needed; Ensure consistency of the title all through the documents
- [ ] Nature of Activity: make sure that only one checkbox is checked under CSO & Special Groups
- [ ] Type of Activity: make sure that the correct type is checked
  - Missing activity types from the ARG are processed under SLIFE
- [ ] Date:
  - if one-day event: put the date
  - if multiple dates: make sure all dates are specified
  - if termlong: use Termlong
  - if yearlong: use Yearlong
- [ ] Time:
  - if termlong/yearlong/online posting/asynch activity: put N/A
  - otherwise, make sure to indicate AM/PM or use 24-hour time format
- [ ] Venue (URL):
  - if it does not fit the portion, put "See link in PPR" instead
  - online posting/upload: URL where content will be posted/uploaded
  - if synchronous activity e.g. seminar/workshop, general assembly: include both URL of conference call and where pub will be posted
  - termlong/yearlong online, indicate URL
  - if termlong/yearlong synchronous series of activities, indicate venue of FIRST synch activity only
  - include links to GALS form and Pre-Registration form if applicable
- [ ] ENP/ENMP: (Estimated Number of Participants/Estimated Number of Member Participants)
  - ENP >= ENMP
  - If Synchronous event, make sure ENMP and ENP is not 0
  - If Asynchronous event, place N/A
  - if termlong/yearlong/online posting/asynch activity: put N/A
- [ ] Online Activity: check YES if purely online If hybrid or F2F: check NO
- [ ] Activity in GOSM:
  - if YES, check YES
  - if NO, check NO,  prepare a SAS and Justification Letter
- [ ] Reach of Activity: make sure to check one checkbox according to the activity
- [ ] Submitted By: Name of Docu-in-charge
- [ ] Noted By: Name of Faculty Advisor
  - if processed under CSO: Mr. Edward Tighe
  - if processed under SLIFE: Ms. Lissa Magpantay
  - Signature is not needed UNLESS there is no Blanket of Approval OR there is Blanket of Approval, BUT The Activity was moved for more than 7 days from the one indicated in the Blanket of Approval
